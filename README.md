# ClassSync — Estrutura inicial da Sprint 1

Primeira etapa do projeto final: preparação da aplicação web Flask e escolha da base visual com Bootstrap.

## Nesta etapa

- aplicação Flask mínima;
- rota pública `/`;
- template base;
- Bootstrap no front-end;
- teste da rota inicial.

Banco de dados, entidades, calendário, autenticação e painel administrativo serão adicionados nas próximas tarefas e sprints.

## Execução

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Acesse `http://localhost:5000`.
